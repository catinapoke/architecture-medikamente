# Решение

Общий список данных:

- Персональные данные пациента
  - Ф. И. О., дату рождения, телефон и электронную почту
  - Доп. данные: 
    - Адрес прописки, 
    - Место работы, 
    - место учебы, 
    - Хронические заболевания
- Финансовые данные: платежи пациентов, доходы и расходы компании 
- Медицинские карты пациентов
- Результаты анализов пациентов
- Данные по товарно-материальным ценностям (ТМЦ)
- Кадровые данные сотрудников: Ф. И. О., должность, зарплата, больничные, реквизиты для выплат
- Учетные данные (Active Directory)
- Технически данные (логи)

По стандарту ISO/IEC 27001 есть следующие категории данных:

- Публичные данные — информация, которая не подлежит ограничению. Данные могут быть свободно распространены и не представляют угрозы для компании. Например, пресс-релизы или публичная информация на сайте.
- Внутренние данные — информация для внутреннего использования в организации. Например, внутренние инструкции, отчёты или данные о работе внутренних систем.
- Конфиденциальные данные — информация, которая имеет высокую ценность и ограничена в распространении. Например, персональные данные, финансовая информация или коммерческая тайна.
- Секретные данные — информация, утечка которой может привести к самым серьёзным последствиям для организации или нарушению законодательства. Например, платёжные данные или государственная тайна.

Разобьем данные выше на категории:
Публичные данные (не требуется защита)

- Публичная информация на сайте

Внутренние данные

- Данные по товарно-материальным ценностям (ТМЦ)
- Технически данные (логи)

Конфиденциальные данные:

- Кадровые данные сотрудников: Ф. И. О., должность, зарплата, больничные, реквизиты для выплат
- Учетные данные (Active Directory)

Секретные данные:

- Персональные данные пациента
- Финансовые данные: платежи пациентов, доходы и расходы компании 
- Медицинские карты пациентов
- Результаты анализов пациентов

В соответствии с категорией данных нужно ввести соответствующие инструменты защиты.
